# WEB KFG Masajes

Web estática (HTML, CSS y JS, sin build) de KFG Masajes: quiromasaje y osteopatía en Sodupe.

## Publicar
Sube el contenido de esta carpeta tal cual a la raíz del hosting (`index.html` en la raíz).

## Estructura
- `index.html`: la página completa
- `css/styles.css`: estilos (paleta y medidas del Manual de Identidad v4)
- `js/main.js`: horario del día y mapa
- `vendor/`: MapLibre GL 4.7.1 en local
- `fonts/`: Outfit (woff2)
- `img/`: fotos en WebP
